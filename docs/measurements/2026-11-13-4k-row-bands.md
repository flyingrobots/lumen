# Measurement record: 4K reference scene with row bands and whole-program builds, 2026-11-13

This is a record of one session. It describes what was measured on the date above, at the commit
below. It is not a statement about any later commit. It repeats
[the earlier 4K record](2026-11-13-4k-reference.md), which was taken at `d8deec4` with the tile
scheduler and the default release profile, for flyingrobots/lumen#28.

## Conditions

| Item | Value |
| --- | --- |
| Commit | `c731bb4` on `perf/row-bands` (row bands, `lto = "fat"`, `codegen-units = 1`) |
| Machine | Apple M5 Pro: 6 "super" and 12 performance cores |
| Where it ran | the `rust-dev:1.96.0` Linux container, through `devrun`, on a Docker VM with 18 CPUs; not native macOS |
| Profile | release (`cargo build --release --locked`) |
| Isolation | `devrun --exclusive --cpus 18 --memory 12g`, one container invocation for all four runs |
| Scene | `lumen-reference-scene/3`, 31 511 triangles |
| Image | 3840 by 2160 (8 294 400 pixels), 16 samples, seed 0, bands of 1 row |
| Rays | 355 318 863 (closest 234 376 387, shadow 120 942 476), as before |

same container, and used the binary built there from freshly checked-out sources. Each was
`lumen render --width 3840 --height 2160 --samples 16 --threads T --out /tmp/4k.png`.

## Reading against the earlier record

- One thread: `total` was 66.156 s here and 72.457 s at `d8deec4`, about 9 % less. That fits the
  gain fat LTO showed at 1280 by 720 (ADR 0003). Each record has one run, from a different
  session.
- 18 threads: `total` was 5.983 to 6.582 s here and 5.828 to 6.232 s before. The ranges
  overlap, and this session's runs are no faster. At 18 threads, run-to-run spread is larger than
  the gain measured at 1280 by 720 (5.8 % there). Three runs cannot separate the two.
- The image is the same bytes.

## Limits of the claim

- One machine, one Docker VM and one container image.
- Two sessions. The reference scene had three runs at 18 threads and one at 1 thread, and
  Fixed Point had four runs of each revision at 18 threads.
- The reference scene has no interleaved before-and-after at 4K: its earlier figures come from
  another session. Fixed Point's comparison is interleaved.
